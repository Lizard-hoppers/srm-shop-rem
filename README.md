# Electronics CRM

CRM для магазина электроники и мастерской по ремонту: клиенты, склад по
ячейкам, ремонты с привязкой к мастеру, приход комплектующих, продажи
(онлайн/офлайн через сайт-бот, офлайн — на месте). Веб-панель для персонала
(FastAPI) + Telegram-бот для клиентов (aiogram), общая SQLite-база.

См. `OPERATIONS.md` — статус по фазам, локальный запуск, деплой.
